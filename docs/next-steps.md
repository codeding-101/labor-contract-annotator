## 一处需要留意的设计约定

法条与范本库里**只放能追溯到官方原文的内容**，规则库里的每条规则都必须绑定真实存在的法条 ID（`statuteRefs`），追溯不到的规则不写；规则里也不复制法条原文，报告要展示哪条就按 ID 从法条库取哪条。

这不是洁癖——作者不是法学专业，这条约束是把「个人法律判断」从系统里彻底移除的唯一办法。改这块代码时请保持这个约束。

**报告层同理：只做标注，不做评价。** 不给综合评分、不给签署建议，只把条款标出来并附上法律条文；签不签由用户自己判断。这条有测试钉住（报告里不含 `score` 与 `recommendation` 字段）。

## 抽取的原则：不要按形状猜（已被真实材料打穿四次）

| 真实打穿 | 当时按什么猜 | 正确做法 |
|---|---|---|
| 试用期工资取成 1500（绩效工资） | 金额取「这一条里最后一个」 | 按「试用期工资」标签锚定，取标签后第一个 |
| 发薪日期被判「合同未提及」 | 关键词只有「发薪／支付日期／发放日期」 | 覆盖真实写法，或干脆升级为事实抽「每月 X 日」 |
| 竞业限制 24312 个月 | `数字 + 年` 这个形状 | 标签锚定 + **合理性检查**：四位数字落在 1900–2200 是日历年份 |
| 一份 PDF 抽出满篇"斜着的 SOH" | 只要有文本层就当读成功了 | 剥掉控制字符，并把**控制字符占比 >2%** 与 **CJK 占比 <40%** 作为"读不出文字"的判据 |
| 一份正常合同被判"读不出文字" | 控制字符**总**占比（每行尾一个 SOH，占 4%） | 只看**夹在正文中间**的控制字符；行首/行尾的是生成器噪声，剥掉即可 |
| 「甲⽅」「⼈⺠」看着正常却一条规则都匹配不上 | 有文字层就当文本可用了 | 字体把字形映射到了**康熙部首/部首补充区**的码位，按 Unicode UCD 等价映射修回统一汉字（`src/cjk-radicals.ts`）。这类错误比乱码危险：文本看着完全正常 |
| 合同期限 2026-09-15 至 2029-09-14 算成 35 个月 | 按"经过时长"算 | 「自 X 起至 Y 止」**含首尾两天**，终止日按含当天计算 → 36 个月。否则会落进"一年以上不满三年"档，把合法的 6 个月试用期误判成超长 |
| 月工资报成 200 元（实际 6000 元） | 标签只认第一次出现 | 标签出现多次时逐个往后试，取第一个后面确实跟着金额的（第一次「转正」后面是「不低于转正工资80%」，没有金额） |
| 工作地点摘成「工作内容和工作地点1.乙方同意…」 | 关键词按出现顺序取 | 文本类事实优先匹配"约定式"写法（`工作地点[为是：]`），"仅提及"的摘录取**命中本行关键词最多**的一句（同样多时取最短），并排除章节标题 |
| Word 路径不修复码位、也没质量自检 | 自检只写在 PDF 读取器里 | 读取器只产出文本，码位修复／控制字符清洗／可用性判定统一放在 `web/src/document.ts`。两份真实 .docx 与一份"从 PDF 复制进 Word"的 .docx 都跑过 |
| 新就业形态合同里"发薪日期"判「未提及」 | 关键词表只有「工资/发薪/支付」 | 这类合同通篇写「劳动报酬」「结算支付」「每月至少…支付一次」，按真实材料补进关键词表 |
| 「合同明确不约定竞业限制义务」被列进"无法判定" | 事实层把"明确不约定"和"没认出来"都归成 `UNRECOGNIZED` | 加 `NOT_AGREED` 这一档：规则判为**不适用**（不报违规也不列进无法判定），关键信息里显示这句话本身。含糊不清才报"无法判定" |

两条硬要求：

1. **标签锚定**：靠标签（「试用期工资」「转正工资」「竞业限制期限」）决定取哪一项，而不是靠位置、顺序或形状。
2. **合理性检查**：荒谬值一律拒绝——期限不可能是 2026 年，工资不可能是 0 元。**宁可报「未识别」，也不给一个看起来合理实际错的值。**

为什么反复强调：这几处都是我读代码、编测试用例发现不了的。我自己编的用例里金额顺序总是对的、关键词总是规范的、不会混进日期。**只有真实材料能打穿它们**——继续收真实材料、把每一处错误变成回归测试，是提升这个工具最有效的办法。

| 年休假 | 天数 | 「年休假10天」 |
| 五险一金 | 是否含公积金 | 「社会保险」「住房公积金」 |
| 工作地点／加班规则／违约责任 | 合同原文整句 | 「工作地点为…」 |
| 保密期限 | 月数 | 「保密期限为3年」 |

升级过程中被真实范本数据当场抓出的三个问题（都已修，且都有回归用例）：

1. **工资构成类事实必须做选项消歧。** 范本第六条「采用以下第 1 种方式支付工资」下面列了 4 种发放方式，其中第 3 种写着「乙方月基本工资 X 元」。不做消歧就会把**没被选中的那一项**里的数额报成基本工资。
2. **候选范围只能是"被选中的项 + 选项清单之前的共用文字"。** 第一版只取了"被选中的项"，结果发薪日期（写在「第 1 种」之前的前缀里：「于每月 X 日前足额支付」）抽不到了。修正后两类都能取到，且仍不碰未选中的选项。
3. **文本类事实要摘整句。** 从标签往后硬截 60 字会跨句，摘出「加班加点。方 2.依法实行以示例为周期…」这种半截不相干的原文——真实范本上第一次跑就出现了。

还有一条经验：**"仅提及"这种状态不能一刀切删掉**。范本里确实有"依法享有带薪年休假"却不写天数的写法，这时正确的做法是如实说"有相关约定，但未能识别出具体内容"并**把原文摘出来**，而不是硬编一个天数，也不是含糊地说"有提及"。

**抽不出来一律报「未提及／未识别」，不要退回"有提及（未核对内容）"这种含糊说法**——那会让人误以为已经核对过了。
